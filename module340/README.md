# VQE Laboratory Series

Eight Google-Colab-ready notebooks aligned with the course sequence:
Module 3 foundations first, then Module 4 VQE.

1. Python, Colab, NumPy, and Qiskit refresher
2. Hamiltonians, eigenstates, and ground-state energy
3. Pauli measurements and energy reconstruction
4. Four-qubit H2 spin-orbital encoding and Jordan-Wigner mapping
5. Reduced two-qubit H2 configuration mixing
6. Complete H2 VQE ground-state calculation
7. H2 bond-length curve, noise, and optional hardware
8. VQE for a small materials-model Hamiltonian

Each notebook contains:
- explanations;
- mostly completed code;
- small YOUR TURN exercises;
- expected outputs;
- reflection questions;
- collapsible instructor solutions.

The real-hardware section is optional and may require minor API updates depending on the IBM Runtime version and available backends when the course runs.
